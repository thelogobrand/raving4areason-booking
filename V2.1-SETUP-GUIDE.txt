RAVING 4 A REASON — VERSION 2.1 SETUP
======================================

INCLUDED
- Shared parent username pre-filled as R4ARparent.
- Admin-assisted parent booking.
- Booking-specific messages for parent, mentor, admin or both.
- Newsletter latest + previous two.
- Google Calendar, Outlook Calendar and Apple/other .ics calendar buttons.
- Donation button on the parent home page.
- Admin Security section to change parent/admin passwords and reset mentor passwords.

1) SUPABASE
Run stage2-complete.sql in Supabase SQL Editor. It is safe to run after the earlier Stage 1/2 SQL because it uses IF NOT EXISTS where possible.

2) NETLIFY ENVIRONMENT VARIABLES
Add these under Netlify > Project configuration > Environment variables:

SUPABASE_URL=https://ejizwiegnxtwglihrxiz.supabase.co
SUPABASE_SERVICE_ROLE_KEY=<copy the secret service_role key from Supabase>
ADMIN_BOOTSTRAP_PASSWORD=R4AR
PARENT_BOOTSTRAP_PASSWORD=R4AR
MENTOR_BOOTSTRAP_PASSWORD=Mentor

Keep the existing:
RESEND_API_KEY=<your Resend key>
BOOKING_FROM_EMAIL=<your verified Resend sender, once available>

IMPORTANT: Never put SUPABASE_SERVICE_ROLE_KEY in app.js, GitHub, or any HTML file. It only belongs in Netlify environment variables.

3) DONATION LINK
Open app.js and change:
const DONATION_URL = "PASTE_DONATION_LINK_HERE";

to the charity's real donation page URL, for example:
const DONATION_URL = "https://example.org/donate";

Until this is changed, the donation button shows a friendly 'not added yet' message.

4) GITHUB / NETLIFY
Upload all changed files to the existing GitHub repository and commit them. Netlify will deploy automatically. Confirm that these functions appear in Netlify Functions:
- send-booking-email
- portal-auth

5) FIRST LOGIN
The initial logins remain:
Admin: admin / R4AR
Parent: R4ARparent / R4AR
Mentor: mentor name / Mentor

After logging into Admin, open SECURITY > PASSWORD SETTINGS to change these. New mentor passwords can be reset individually there.

6) TEST ORDER
- Parent login with pre-filled R4ARparent.
- Admin login.
- Change the parent password, log out, and test the new password.
- Reset one mentor password and test it.
- Make a booking and test Google, Outlook, and .ics calendar options.
- Test the donation button after adding the real URL.
- Confirm existing messages/newsletters/bookings still work.

SECURITY NOTE
The main portal passwords are verified in a Netlify server function and stored as salted password hashes in Supabase. The service-role key must remain private in Netlify.
